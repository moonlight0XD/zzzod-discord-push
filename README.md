# Discord 頻道推送

絕區零一條龍插件。讓通知直接發到 Discord **頻道**，並附上遊戲截圖縮圖。

## 功能

- **新增「Discord Webhook」通知方式**：不需要機器人，貼上頻道的 Webhook 網址就能用。
  - 通知以卡片顯示：標題、內容，右側是當時的遊戲截圖縮圖。
  - 可以自訂顯示名稱與頭像；留空則使用 Webhook 自己的設定。

插件只在執行時新增推送管道，不修改主程式檔案，不影響一條龍自動更新。

## 使用方式

1. Discord 頻道 →「編輯頻道」→「整合」→「Webhook」→「新 Webhook」→「複製 Webhook 網址」。
2. 安裝插件後重新啟動一條龍（或在插件頁按「刷新」）。
3. 「設定 → 通知」，通知方式選 **Discord Webhook**，填入 Webhook 網址，按「測試」。

只接受 Discord 官方網域的 Webhook 網址（`discord.com`、`discordapp.com`，含 `ptb.`、`canary.`），格式為 `https://discord.com/api/webhooks/…`。

## 資料與安全

- **Webhook 網址等於頻道的發文金鑰**：拿到網址的人就能往該頻道發訊息，請勿公開。
- **網址以明文儲存**：由一條龍主程式統一存放在 `config/push.yml`，沒有加密。分享設定檔或備份前請先移除或改掉。
- **會傳送的內容**：通知的標題、內容，以及當時的遊戲截圖，會發送到你填寫的 Webhook 所屬頻道；頻道裡看得到的人都能看到。
- **錯誤與日誌**：推送失敗時只記錄 HTTP 狀態碼或錯誤類型，不會把 Webhook 網址寫進日誌或錯誤訊息。

## 風險說明

- `network`：只向 Discord 官方網域發送通知與截圖。若在「頭像網址」填了網址，Discord 會到該網址讀取頭像圖片。
